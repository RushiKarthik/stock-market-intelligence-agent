# Indian Market Intelligence Agent

An AI-powered research pipeline that:

1. Collects Indian/global market data and news
2. Uses an LLM to plan and analyze research
3. Generates a structured research brief
4. Verifies claims against collected evidence
5. Generates a final market intelligence report
6. Sends the report automatically by email
7. Runs through Windows Task Scheduler

TECH STACK:

Python
Groq LLM
LLM Tool Calling
yFinance
News/RSS
AI Research Pipeline
Fact Verification
Gmail SMTP
Windows Task Scheduler
